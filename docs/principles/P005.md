# P005: Security Standards

## Definition
P005 validates comprehensive security requirements and authentication mechanisms. It ensures that security schemes are explicitly defined, consistently applied, and machine-readable, enabling automated security posture verification without manual review.

## DDT Axiom Mapping
**Observability Axiom** — Security schemes must be machine-readable for automated enforcement. A security configuration that requires human interpretation to understand cannot be automatically verified or enforced in a CI/CD pipeline.

## Severity
Critical

## AutoFixable
No — security decisions require human judgment. The tool reports gaps but cannot safely generate security schemes, as incorrect security configuration is worse than missing configuration.

## Checks Performed
1. At least one security scheme is defined in components/securitySchemes
2. Global security requirements are specified (top-level security array)
3. Operation-level security overrides are valid (reference defined schemes)
4. OAuth2 scopes are documented with descriptions
5. API key schemes have proper parameter descriptions (name, location)
6. Authentication headers are specified (Bearer token format, etc.)
7. Security requirements are consistent (no operations accidentally unprotected)
