\chapter{End-to-End Workflow}
\label{ch:workflow}

This chapter describes how the DriveBy binary is deployed into Kubernetes-native GitOps pipelines. Section~\ref{sec:event-pipeline} presents the event-driven pipeline that triggers validation from pull request events. Section~\ref{sec:staging-dag} details the seven-step workflow DAG that orchestrates validation, testing, and feedback.
